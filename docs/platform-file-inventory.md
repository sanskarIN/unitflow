# Generated Flutter platform file inventory

This file is machine-maintained by `scripts/update_platform_inventory.py`.

It lists Flutter-generated platform scaffold files that are intentionally committed under `apps/unitflow_app`. The human-oriented role descriptions for first-party source, documentation, automation, and configuration files remain in `docs/repository-inventory.md`.

Do not edit the generated list by hand. After adding, removing, or regenerating a platform project, stage the intended platform files and run:

```bash
python3 scripts/update_platform_inventory.py
```

The main repository inventory validator combines this generated list with `docs/repository-inventory.md` and still requires every tracked file to be documented exactly once.
