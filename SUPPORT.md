# UnitFlow Support

## Help and bug reports

For reproducible bugs, open a GitHub issue with:

- UnitFlow version or commit
- Platform and OS version
- Flutter/Rust versions when relevant
- Exact source and destination units
- Input value and expected result
- Steps to reproduce
- Logs or screenshots with private information removed
