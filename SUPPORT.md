## Before requesting help

Please include:

- UnitFlow version/commit;
- operating system and version;
- Flutter and Rust versions when relevant;
- exact command or workflow that failed;
- complete non-sensitive error text;
- minimal reproduction steps.

Never send passwords, access tokens, signing keys, private user data, or payment information.
